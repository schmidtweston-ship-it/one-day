# One Day

A warm, big-text recovery companion, one day at a time. Clean-date counter with milestones, an "I want to use" walk (rate the craving, HALT check, a ten-minute spoken ride-the-wave timer, play the tape forward, call your people, rate it again), morning "just for today" plan, an honest night check with gratitude, a kind restart after a slip, meeting finders (AA, NA, SMART Recovery, FindTreatment.gov), and 988 plus the SAMHSA help line on every screen.

Offline. No account. Everything stays on the phone. Save a copy / Bring back a copy in Settings.

Not a replacement for a sponsor, a program, or professional care.

Built by Ada for the Schmidt family.
